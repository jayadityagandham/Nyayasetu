## 📌 Overview

**NyayaSetu** is a full-stack legal intelligence platform designed for the Indian legal ecosystem. It ingests raw court judgments (PDF/TXT), segments them into rhetorical roles, generates structured summaries, maps legacy **IPC sections to BNS 2023** equivalents, and answers legal questions — all grounded in a hybrid RAG pipeline to eliminate hallucinations.

### Key Highlights

- 🔍 **Hybrid RAG** — BM25 (sparse) + FAISS (dense) retrieval with Reciprocal Rank Fusion
- 📄 **7 Rhetorical Roles** — Facts, Issue, Argument, Statute, Precedent, Ratio, Decision
- 🧠 **7 ML Models** orchestrated via HuggingFace Inference API
- 🌐 **Multilingual** — English, Hindi, Telugu output via IndicTrans2
- 📊 **Built-in Evaluation** — ROUGE, Flesch-Kincaid, RAGAS proxy metrics
- 🗣️ **Voice I/O** — Whisper STT + gTTS text-to-speech

## 🚀 Features

### 1. Rhetorical Role Segmentation & Summarization
Classifies judgment sentences into 7 roles (Facts, Issue, Argument, Statute, Precedent, Ratio, Decision) and independently summarizes each using PEGASUS.

### 2. IPC ↔ BNS 2023 Mapping
Automatically maps legacy Indian Penal Code sections to their Bharatiya Nyaya Sanhita 2023 equivalents using a comprehensive regex + lookup system.

### 3. Hybrid RAG-Grounded Legal QA
Combines BM25 keyword search with FAISS semantic search via Reciprocal Rank Fusion. Answers are generated by LLaMA-3/Mistral-7B strictly grounded in retrieved statutes.

### 4. Similar Case Retrieval (ILDC)
Searches 35,000+ Indian Supreme Court cases from the Indian Legal Documents Corpus using Sentence-BERT + FAISS cosine similarity.

### 5. Readability Control
Three-tier output: **Basic** (citizens), **Student** (law students), **Advanced** (practitioners) — dynamically adjusted via prompt engineering.

### 6. Multilingual Output
Translates all outputs to **Hindi** and **Telugu** via IndicTrans2 (AI4Bharat).

### 7. Voice Input & Audio Output
Whisper-powered voice queries + gTTS audio responses for accessibility.

### 8. Built-in Evaluation Dashboard
ROUGE scores, Flesch-Kincaid readability, and RAGAS proxy metrics (Faithfulness, Relevance, Context Precision).

## ⚡ Quick Start

### Prerequisites
- Python 3.9+
- Node.js 18+
- [HuggingFace API Token](https://huggingface.co/settings/tokens) (free tier works)

### 1. Clone & Install

```bash
git clone https://github.com/jayadityagandham/Nyayasetu.git
cd Nyayasetu
```

```bash
# Backend
pip install -r requirements.txt
pip install fastapi uvicorn python-multipart

# Frontend
cd frontend
npm install
```

### 2. Run

**Option A — Both servers (recommended):**
```bash
# Terminal 1: Backend
uvicorn api:app --host 0.0.0.0 --port 8000

# Terminal 2: Frontend
cd frontend
npm run dev
```

**Option B — Windows one-click:**
```bash
run_app.bat
```

**Option C — Streamlit standalone:**
```bash
streamlit run app.py
```

### 3. Open
- **Frontend** → [http://localhost:3000](http://localhost:3000)
- **API Docs** → [http://localhost:8000/docs](http://localhost:8000/docs)

## 📊 Evaluation Metrics

| Metric | Purpose | Target |
|--------|---------|--------|
| **ROUGE-1 / ROUGE-2 / ROUGE-L** | Summarization quality | Higher = better |
| **Flesch-Kincaid Grade** | Readability level verification | Basic < 8, Advanced > 12 |
| **Flesch Reading Ease** | Citizen-friendliness | Basic > 65, Advanced < 40 |
| **RAGAS Faithfulness** | LLM answer grounded in context | > 0.7 |
| **RAGAS Answer Relevance** | Answer addresses the query | > 0.7 |
| **RAGAS Context Precision** | Retrieved docs are relevant | > 0.6 |
